Movie Recommender System
This project is a Movie Recommendation System that recommends movies based on user preferences. It uses a content-based filtering approach to suggest movies similar to the ones selected by the user.

Project Overview
The system is built using Python and Streamlit for deployment. It preprocesses movie metadata from the TMDb 5000 dataset and allows users to explore and discover movies based on genres, keywords, and popularity.

Features
Content-Based Filtering: Recommends movies similar to user preferences using genres, keywords, and other metadata.
Interactive Web Application: Built with Streamlit for a user-friendly experience.
Efficient Preprocessing: Preprocessed data stored as .pkl files for fast loading.
Scalable Design: Capable of handling datasets with large entries efficiently.

Dataset Information
Source: TMDb 5000 dataset
Total Rows: 4803
Columns:
budget: Budget of the movie
genres: Genres of the movie
homepage: Official homepage of the movie
id: Unique ID of the movie
keywords: Keywords associated with the movie
original_language: Original language of the movie
original_title: Original title of the movie
overview: Short summary or synopsis of the movie
popularity: Popularity score of the movie
production_companies: Companies involved in production
production_countries: Countries where the movie was produced
release_date: Release date of the movie
revenue: Revenue generated by the movie
runtime: Duration of the movie
spoken_languages: Languages spoken in the movie
status: Status of the movie (Released, etc.)
tagline: Tagline of the movie
title: Title of the movie
vote_average: Average rating of the movie
vote_count: Total votes received by the movie
